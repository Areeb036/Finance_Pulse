# Finance Pulse: Banking Analytics Dashboard

## Overview
End-to-end banking risk analytics solution using MySQL, Python, and Power BI to transform banking data into actionable lending insights for a $2.19B loan portfolio across 1,499 clients.

## Key Features
- **Interactive Dashboards**: 4 specialized views with filtering by banking relationship, gender, and time periods
- **Risk Assessment**: Lending analysis by income bands revealing mid-income clients ($207.58M) as primary borrowers
- **Regional Insights**: European markets showing highest loan activity ($181.51M)
- **Client Segmentation**: Engagement timeline correlation with deposit behavior

## Technical Implementation
- **Data Pipeline**: MySQL → Python (Pandas, NumPy) → Power BI
- **Custom Metrics**: Engagement Timeframe, Income Band categorization, Processing Fees
- **DAX Functions**: SUM, DISTINCTCOUNT, SUMX, SWITCH, DATEDIFF
- **Visualizations**: Donut charts, treemaps, bar charts, KPI cards
